# Cruiser Trader

A marketplace for Toyota Land Cruiser vehicles, parts and auctions, with listings filtered by the series and year of your rig.

**Stack:** TanStack Start (React 19), Tailwind CSS 4, Vite, deployed on Netlify. Photos are served through Netlify Image CDN.

## Run locally
```bash
pnpm install
netlify dev   # or: pnpm dev
```

## Roadmap
For now the site runs on sample data. See [PLAN.md](PLAN.md) for the planned database, accounts, auctions, messaging and payments.
